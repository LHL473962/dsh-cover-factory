# 版本策略

## 版本号规则

- **次版本号（0.x → 0.y）**：只在“巨型更新”时提升——整套能力换代、不兼容变更、或达到一个明确的里程碑。
- **补丁号（0.2.0 → 0.2.1）**：普通功能新增与修复，不轻易提升次版本号。
- 大版本（1.0）：插件对外正式发布、接口稳定。

## 0.3.0 的触发条件（当前）

必须同时满足：

1. 所有“预期收益 ≥ 中”的改进方案都评估过（见 docs/IMPROVEMENT_BACKLOG.md）
2. 回归集指标不退化
3. **“清亮”目标达成**：盲听确认换声结果不再有“麦太差/塑料感”，且谱平坦度接近原声水平

未达成前，所有改动只升补丁号（0.2.x）。

## 发版流程

1. 更新 CHANGELOG.md
2. 改 package.json + index.js（版本号一致）
3. 跑 tests/package.mjs、tests/smoke.mjs
4. 打 tag 并推送
