# 用户提示词模板（翻唱工厂 0.2.0）

> 目的：让普通用户对普通 AI 说一次话就能跑对，不依赖“猜”。
> UI 面板目前**没有经过真实用户实测**，日常请用对话方式；UI 仅作观察和调音。

## 一、完整版（推荐复制后改括号内容）

```
帮我做一首翻唱，按翻唱工厂的流程跑。

歌手：<歌手名>（声部：男 / 女 / 自动）
好球区（音色参考，2–3 首）：<歌名 A>、<歌名 B>
目标曲：<歌名>，文件在 <绝对路径>

素材来源：
- 本地目录：<绝对路径，没有就写“无”>
- 本机音乐软件：网易云 / QQ音乐 / 酷狗 / 酷我（勾选有的）
- 联网搜索：开 / 关（开的话我会确认版权）

训练步数：9000（能听）/ 15000（完整）
其他：哼唱段用自动；音域不够时先告诉我缺多少，不要硬训。
```

## 二、最小可用版（只有本地素材时）

```
翻唱：<歌手名>，好球区 <歌名A>、<歌名B>，
目标曲 <绝对路径>。
素材用本地目录 <绝对路径>，不联网，训练 9000 步。
```

## 三、让 AI 自己找素材版

```
翻唱：<歌手名>，目标曲 <绝对路径>。
素材：先扫我的本机音乐软件（网易云/QQ/酷狗/酷我），
不够再联网搜索（我确认版权）。
训练 15000 步，好球区你从素材里挑 2 首最有代表性的。
```

## 四、每个字段为什么必须有

| 字段 | 缺了会怎样 | 说明 |
|---|---|---|
| 歌手名 | 声库名/搜索关键词都不对 | 用正名，别用别名 |
| 好球区 | 音色可能跑偏 | 2–3 首，权重 ×6 |
| 目标曲 + 路径 | 只能训到 train，出不了成品 | 必须是音频文件 |
| 素材来源 | 没素材直接失败 | 目录/客户端/联网至少一个 |
| 是否联网 | 默认不联网，可能素材不足 | 联网要确认版权 |
| 步数 | 默认 9000，能听但不完整 | 15000 更完整，再高边际很小 |

## 五、AI 应该主动追问的情况

```
① 没给目标曲 → 问“目标曲是哪首、文件在哪”
② 没给素材来源 → 问“素材在本地目录，还是扫音乐软件，还是联网找”
③ 好球区没给 → 建议从素材里挑 2–3 首，或问用户偏好
④ 歌手名像别名 → 先确认正名
⑤ 音域检查失败 → 报缺多少 Hz，问“补素材还是先放行”
```

## 六、UI 使用警告（视频里必须说）

```
UI 面板目前没有经过真实用户实测：
- 它只是把同一套流程画成表单
- 字段多、容易漏填（素材来源、目标曲路径）
- 遇到报错时信息不如对话清楚

建议：日常用对话；UI 用来“看进度”和“调音台”就够了。
```

## 七、视频里的演示口径

- 演示时**打完整提示词**，不要用“给我跑一首 XX”这种模糊句
- 让 AI 在视频里明确复述：歌手、好球区、目标曲、素材来源、是否联网、步数
- 再说一句“它还会先检查素材音域，不够会告诉你”
