# Token / 对话成本说明（估算）

> 先说清：**插件在本机执行，不消耗模型 token**。
> 花 token 的是你和 AI 的对话：每一轮都会带上上下文，轮次越多、日志越长，越贵。

## 一、什么在消耗

| 项目 | 是否耗 token | 说明 |
|---|---|---|
| 下载依赖 / 分离 / 训练 / 混音 / 导出 | ❌ | 本机进程，不经过模型 |
| AI 调用工具、读日志、报进度 | ✅ | 每次工具返回都进上下文 |
| UI 面板点击 | ❌ | 直接调本地 API |
| 反复问同一件事 / 重复排错 | ✅✅ | 最浪费 |

## 二、估算（经验值，非精确计费）

| 场景 | 轮次 | token 估算 |
|---|---|---|
| 首次安装（含排错） | 10–30 | **5–15 万** |
| 跑一首（素材已在本地） | 3–8 | **2–5 万** |
| 素材搜索 + 下载 + 分离 + 音域分析 | 5–15 | **3–10 万** |
| 单次失败重试 | 1–3 | **1–3 万** |
| 只查进度（status） | 1 | 约 1–3 千 |
| 用 UI 跑 | 0 | 0 |

## 三、怎么省

```
① 第一次就把提示词给全（歌手/好球区/目标曲/素材来源/联网/步数）
② 让 AI 只读日志末尾，不要整篇读
③ 训练期间不要频繁追问，用「看下进度」一句话即可
④ 出问题先让它报 decision/错误码，再决定要不要排错
⑤ 已经出过成品的参数，下次直接复用，不要重训
```

## 四、和视频口径一致的说法

> “插件本身不花钱，花钱的是你和 AI 的对话。
> 一次跑通大概几万 token；装环境排错可能十几万。
> 想省钱就把提示词一次说全，别让它反复试。”

## 五、注意

- 不同模型/平台计价不同，这里只给 token 量级，不给金额
- 安装阶段如果反复失败，成本会显著上升——先跑 doctor 再排错
- 训练本身很便宜（本机算力），对话才是成本项
