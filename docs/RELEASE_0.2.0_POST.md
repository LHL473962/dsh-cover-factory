## 长版（专栏/README 摘要）

# 翻唱工厂 0.2.0：从歌手名到成品的一条流水线

### 它做什么

- 素材：本地目录 / 本机音乐客户端 / B站搜索（需确认版权）
- 分离：kim 或 BS-RoFormer ep317
- 训练：RVC 声库，自填步数（默认 9000），支持 40k/48k
- 换声：旧版 RVC 推理，支持 f0 方法切换
- 混音：old（原比例 + 混响链 + -14 LUFS）/ new（等响基准 + EQ/饱和 + 峰值保护）
- 质检 + 导出：质检不合格直接拒绝出片，报告写清原因

### 0.2.0 新增

1. 两套混音标准，按声库的分离方式自动选择
2. 哼唱段五选项：自动判断（无词区间保留原声）/ 保留 / 替换 / 静音 / 手动标注
3. 自动增益：活跃帧中位或 LUFS 口径，逐首对齐
4. 内置调音台：10 段均衡 + 增益/声像/饱和/混响 + 总线压缩/限制，可导出 WAV
5. 素材音域覆盖检查：素材 p95 不够目标就拒绝训练
6. 导出硬闸：qa 不合格 → EXPORT_BLOCKED_QA

### 安装

```
git clone https://github.com/LHL473962/dsh-cover-factory
（DSH 插件目录安装，或跑 scripts/install-plugin.ps1）
```

依赖由插件引导安装：torch（按显卡选 cu128/cu121）、Applio、旧版 RVC、fairseq 预编译包（py310）、MSST 与模型。

### 硬件

- NVIDIA 显卡，显存 ≥8G（<5G 会拦）
- 磁盘 ≥20G（模型 + 切片 + 训练产物）
- 不支持 AMD / Intel 核显（依赖 CUDA）

### 已知限制（先说清楚）

- 清亮度还没完全解决：换声后 4k 以上偏暗、气声被平滑
- 嘎裂声/气泡音会“哑一下”（RVC 架构限制，换声库也一样）
- 高音区音色可能切换，需要素材音域覆盖足够
- 48k 训练暂无清亮收益，仅作可选
