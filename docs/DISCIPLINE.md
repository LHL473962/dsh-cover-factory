# 纪律：同类错误不超过三次

## 规则

1. 每次同类错误发生，记一次；第 3 次必须停下，**先写自动拦截，再继续做**。
2. 任何手动流程（手工换声/手工混音/复制文件）都必须先过对应检查；不许绕过引擎“图快”。
3. 修复要跨文件同步：引擎、脚本、工具、文档至少各查一遍。
4. 结论只写“测得什么”，不写“听感如何”；听感必须由人确认。

## 手动混音/换声的强制流程

```
python engine/tools/manual_mix.py \
  --vocal <换声后人声> --inst <伴奏> --source-vocal <原始人声 stem> \
  --out <输出 mp3> [--preset spica]
```

它会：
1. 用 check_vocal 检查源 stem（打击比/相关/浊音率）
2. 按 ratio_src 计算增益（不允许手填）
3. 用统一混音链（默认或 preset）
4. 归一化到 -14 LUFS、限幅 -2dB
5. 输出前校验：比例偏差 ≤0.5 dB、峰值 ≤-1 dBFS
6. 打印 md5


## 播放器报 Unsupported channel layout（已发生 2 次）

**原因**：导出 mono mp3，部分播放器不支持单声道布局。
**修复**：所有交付音频强制立体声：

```
ffmpeg -i in.wav -ac 2 -ar 44100 -codec:a libmp3lame -b:a 320k out.mp3
```

**闸**：导出脚本/手工命令必须带 `-ac 2`；交付前用 ffprobe 确认 `channels=2`。
